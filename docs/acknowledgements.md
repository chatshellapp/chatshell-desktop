ChatShell uses these open-source projects:

- [Tauri](https://tauri.app/) — Build smaller, faster, and more secure desktop applications
- [Rig](https://rig.rs/) — Modular LLM application framework
- [rmcp](https://github.com/modelcontextprotocol/rust-sdk) — Model Context Protocol SDK for Rust
- [Radix UI](https://www.radix-ui.com/) — Unstyled, accessible UI components
- [shadcn/ui](https://ui.shadcn.com/) — Beautiful, customizable components built with Radix UI and TailwindCSS
- [React](https://react.dev/) — The library for web and native user interfaces
- [OpenUI](https://openui.com/) — Generative UI language and React runtime for rendering streamed model output
- [Recharts](https://recharts.github.io/) — Composable charting library built on React
- [KaTeX](https://katex.org/) — Fast math typesetting for the web
- [Mermaid](https://mermaid.js.org/) — Diagrams and charts from Markdown-like text
